# Fontes dos modelos estáticos
Os JSON deste diretório descrevem o layout e um exemplo fictício para a produção dos ficheiros finais. Não são dados de um comprador e não devem originar um editor de CV. O Antigravity gera DOCX/PDF estáticos seguindo `docs/08_PRODUCAO_RECURSOS.md` e `design/`.

O CSV vazio é um recurso de apoio já utilizável. O gestor online de candidaturas é uma funcionalidade distinta: organiza oportunidades, não compõe currículos.
